# Melo English

Рабочее отдельное Mini App для изучения английского. Музыкальная версия в корне репозитория сохранена.

URL после GitHub Pages: https://ejidzechannel-lab.github.io/melospace/english/

## Готово
- 16 бесплатных уроков: 4 вводных A0 и 12 A1 с переходом к основам A2, 84 слова и фразы, пояснения грамматики и лексики.
- Перевод с выбором ответа, сборка фразы, ввод на английском, аудирование через Web Speech API с текстовой альтернативой.
- Карта уроков, критерий прохождения 60%, XP, серия дней, ежедневная цель.
- Повторение ошибок: фраза уходит после двух верных повторений. Повторение восстанавливает энергию; нехватка энергии не прерывает обучение.
- Прогресс на устройстве, резервная копия JSON; серверная синхронизация после установки SQL/функции.
- Персонаж Melo, реакции на ответы, звуки с выключателем, поддержка reduced motion.
- Дополнительный набор «В поездке — как дома»: шесть уроков, 36 фраз. Цена 199 Stars, разовый доступ. Продажи по умолчанию отключены.

## Подключение сервера
1. Supabase SQL Editor: выполнить `supabase/migrations/20261111_english.sql`.
2. Обновить `melospace-api` кодом `supabase/functions/melospace-api/index.ts`. JWT gateway оставить выключенным: API проверяет подпись Telegram самостоятельно. Health должен показывать version 8.
3. Открыть именно Mini App через бота: в BotFather /mybots → Bot Settings → Menu Button указать URL /melospace/english/.
4. Синхронизация использует существующий TELEGRAM_BOT_TOKEN. Чужой Telegram ID из клиента сервер не принимает: ID извлекается только из проверенного initData.

## Перед приёмом оплаты
- Бесплатные уроки работают до включения продаж; приложение не изображает успешную покупку.
- В Edge Functions → Secrets задать `MELO_SUPPORT_CONTACT` (реальный контакт поддержки, например собственный @username) и `MELO_ADMIN_USER_ID` (числовой Telegram ID владельца; приложение показывает свой ID в профиле).
- В профиле администратору станет доступна кнопка «Подключить события Stars». Она сохраняет существующий webhook и secret, добавляя pre_checkout_query к message. До этого реальные покупки недоступны.
- После тестирования оплаты/возврата задать `MELO_ENGLISH_SALES_ENABLED=true`. Стоимость и товар проверяются сервером. Ответ на pre-checkout не даёт доступ: только successful_payment и транзакция PostgreSQL открывают набор.
- Проверить на отдельном аккаунте: XTR=199, проверка личности покупателя, успешный платёж, повтор доставки уведомления, обновление покупок, покупка на втором устройстве, возврат.
- Поддержка: /paysupport. Администратор может отправить боту `/refund UUID_ЗАКАЗА` для возврата Stars через refundStarPayment. Выполненный возврат закрывает доступ, выданный этим заказом. Перед повтором команды при ошибке проверить журнал Stars и таблицу english_orders.
- Сохранить подтверждённые условия продажи и поддержки. До проверки живого платежа нельзя считать оплату проверенной end-to-end.

## Ограничения
- Это самостоятельный начальный курс, не полный курс до свободного владения языком и не продукт Duolingo.
- Письменные задания проверяют заданную фразу, принимают распространённые сокращения и игнорируют регистр/пунктуацию; свободные варианты перевода ИИ не оценивает.
- Озвучка зависит от английских голосов браузера/ОС. Есть текстовый вариант, когда звук недоступен. Запись речи и оценка произношения не заявлены.
- XP — мотивационный показатель, не валюта и не соревновательный рейтинг. Прогресс валидируется по известным ID и объединяется под блокировкой строки БД.
- Free-проект Supabase может приостанавливаться при неактивности. При недоступности сервера продолжают работать бесплатные уроки и локальное сохранение; покупки блокируются.

## Проверено в разработке
Проверки синтаксиса JS, полнота курсов, правильные ID, нормализация сокращений, переходы/порог прохождения, XP, слияние прогресса; серверные проверки цены, валюты, покупателя, повторной покупки и выдачи только после оплаты. Ручную проверку SQL и живых платежей нужно выполнить после подключения Supabase.


Обновление обучения: выбор A0/A1/A2 (старт внутри курса), мини-тест из 8 вопросов без заявления о сертификации CEFR. Выбор хранится отдельно на устройстве и не выдаёт XP или фиктивно завершённые уроки. Перед каждым уроком доступны карточки всех новых слов/фраз. A0 — только узнавание перевода; в первом прохождении других уроков нет письма по памяти, сборка сопровождается образцом.


## Обновление: анимации и тематические ступени
48 уроков, 210 слов и фраз. A0: 6, A1: 8, A2: 8, B1: 8, B2: 8, C1: 6, C2: 4. Продвинутые ступени — ограниченная тематическая практика, не полные программы CEFR. Тест из 16 вопросов — приблизительный подбор старта, без проверки свободной речи.
Golos Text (кириллица и латиница) хранится локально в fonts; лицензия OFL приложена. Мело: дыхание, приветствие лапой, радость, поддержка, размышление, слушание, завершение урока. Голова деформируется отдельно через WebGL; при отсутствии WebGL остаются Canvas и CSS. При reduced-motion движение отключено, при скрытии вкладки активная анимация останавливается.
