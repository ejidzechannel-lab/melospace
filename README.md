# MeloSpace — Telegram Mini App

Рабочий клиентский прототип. Файлы приложения находятся в dist/.

## Возможности
- Адаптивный интерфейс, главный экран, поиск, медиатека, избранное.
- Добавление собственных аудиофайлов и сохранение файлов, избранного и плейлистов в IndexedDB.
- Очередь, перемотка, переключение треков, случайный порядок, повтор трека и управление громкостью на широком экране.
- Telegram Web Apps SDK: ready, expand, цвета приложения при запуске внутри Telegram.
- Media Session для поддерживаемых браузеров.

## Ограничения текущей версии
Данные локальны для браузера/устройства и могут исчезнуть при очистке данных или выселении браузерного хранилища. Нет синхронизации аккаунта, серверной загрузки, общего каталога, оплаты или реальных рекомендаций. «Моя волна» — случайный микс из добавленных файлов. Поддержка форматов зависит от браузера. Приложение не извлекает встроенные аудиотеги: имя «Исполнитель - Название.mp3» разбирается по разделителю.

## Следующий этап
1. Выбрать источник музыки с правами на потоковое воспроизведение.
2. Подключить backend: проверка Telegram initData, аккаунты, база музыки и плейлистов, объектное хранилище аудио.
3. Разместить приложение по доступному пользователям HTTPS URL и настроить Mini App / кнопку меню бота через BotFather. Текущая частная публикация предназначена для просмотра владельцем, а не для массового запуска бота.
4. Проверить на Telegram Android, iOS и Desktop: звук, фон, safe areas и ограничения хранилища.
5. При необходимости добавить подписку с серверной проверкой платежей.

Токен бота хранится только на сервере. Клиентские данные Telegram нельзя считать проверенной авторизацией. Документация: https://core.telegram.org/bots/webapps

## Проверка
Синтаксис JavaScript: node --check dist/app.js.
Статическая публикация не требует сборки. Для локальной проверки можно обслужить dist любым HTTP сервером.
